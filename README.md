# معرفی و امکانات پروژه — Rasa Teams CMS

این پروژه یک **سایت شرکتی/آژانسی کامل** (پورتفولیو + وبلاگ + رزومه + فرم تماس) به همراه یک **پنل مدیریت اختصاصی (rasa-manager)** است که کاملاً با PHP خام (بدون فریم‌ورک) و MySQL نوشته شده و برای اجرا روی **هاست اشتراکی معمولی (cPanel)** طراحی شده است. زبان رابط کاربری فارسی و راست‌به‌چپ (RTL) است.

> این فایل فقط برای معرفی قابلیت‌هاست. راهنمای گام‌به‌گام نصب و استقرار روی هاست را در فایل
> `راهنمای جامع استقرار.md` بخوانید.

---

## ۱. بخش عمومی سایت (فرانت‌اند)

- **صفحه اصلی (`index.html`)** با انیمیشن‌های حرفه‌ای مبتنی بر **GSAP + ScrollTrigger** و **Three.js**.
- **درباره ما (`about.html`)**: معرفی تیم، افتخارات/جوایز (Awards) و برندها/مشتریان (Brands) — همه از پنل مدیریت قابل ویرایش.
- **وبلاگ/مقالات (`articles.html` + `article.php`)**:
  - دسته‌بندی مقالات، محاسبه‌ی خودکار زمان مطالعه، اسلاگ فارسی/انگلیسی.
  - صفحه‌ی اختصاصی نویسنده (`author.php`) با پروفایل عمومی.
  - سیستم نظرات با تأیید ادمین و **فیلتر اسپم قانون‌محور داخلی** (بدون سرویس بیرونی).
  - پیش‌نمایش مقاله پیش از انتشار (Preview).
  - نسخه‌ی PWA اختصاصی وبلاگ (قابل نصب، `articles-manifest.json`).
- **نمونه‌کارها/پروژه‌ها (`projects.html` + `project.php`)**: دسته‌بندی، پیش‌نمایش، صفحه‌ی اختصاصی هر پروژه.
- **رزومه (`resume.php`)** و **تماس با ما (`contact.html`)** با فرم تماس محافظت‌شده توسط **کپچای تصویری (GD)**.
- **جست‌وجوی سراسری سایت (`search.html`)** بین مقالات و پروژه‌ها.
- **صفحات خطای اختصاصی** (403 / 404 / 500 / 502) و **حالت تعمیرات (`maintenance.php`)** قابل روشن/خاموش‌کردن از تنظیمات.
- **سئوی کامل**: متاتگ‌ها، Open Graph، Twitter Card، Schema.org (JSON-LD) برای مقاله/پروژه/نویسنده، `sitemap.php` پویا و `robots.txt`.
- **PWA در کل سایت**: Service Worker، مانیفست، نصب روی موبایل/دسکتاپ.
- فونت فارسی **Vazirmatn** و کتابخانه‌های گرافیکی به‌صورت وندور محلی (بدون وابستگی به CDN خارجی).

## ۲. پنل مدیریت — rasa-manager

پنل مدیریتی تک‌صفحه‌ای (Tabs) با ورود امن، احراز هویت مبتنی بر Session و توکن CSRF:

- **داشبورد**: آمار کلی سایت، نمودار بازدید ۷ روز اخیر، آمار همیشگی صفحات، وضعیت سلامت سیستم (System Health).
- **مدیریت مقالات**: ویرایشگر متن غنی (RTE) با پشتیبانی از تصویر/ویدیو/آهنگ/رنگ، آپلود تصویر و رسانه، ذخیره‌ی پیش‌نویس/پیش‌نمایش.
- **مدیریت پروژه‌ها**: همان ویرایشگر غنی، آپلود کاور، دسته‌بندی.
- **مدیریت دسته‌بندی‌ها (Taxonomy)** برای مقالات و پروژه‌ها.
- **مدیریت نظرات**: تأیید/رد/پاسخ به نظرات، حذف، فیلتر اسپم.
- **صندوق پیام‌های فرم تماس**: مشاهده، علامت‌گذاری خوانده‌شده، حذف.
- **مدیریت تیم**: اعضای تیم، تیم توسعه (Dev Team)، افتخارات/جوایز با ترتیب قابل جابه‌جایی (Reorder)، برندها/مشتریان — هرکدام با لینک شبکه‌های اجتماعی.
- **مدیریت محتوای صفحات ثابت** (About/Contact و غیره) از داخل پنل.
- **مدیریت ادمین‌ها با سطح دسترسی دقیق (Granular Permissions)**: هر ادمین فقط به بخش‌هایی که اجازه دارد دسترسی دارد؛ ثبت **لاگ فعالیت (Activity Log)** برای اقدامات حساس.
- **پروفایل و تغییر رمز عبور** برای هر ادمین.
- **پشتیبان‌گیری و بازیابی (Backup/Restore)**: خروجی ZIP شامل دیتابیس (SQL) + فایل‌های آپلودی، هم به‌صورت دستی و هم **زمان‌بندی‌شده‌ی خودکار**.
- **بخش ایمیل اختصاصی (تب Email)** — توضیح کامل در بخش بعد.
- **تنظیمات سایت** از یک تب مرکزی (SEO، ایمیل، نمایش و ...).
- نصب به‌صورت PWA برای پنل مدیریت (`admin-pwa-install.js`، Service Worker جدا).

## ۳. سیستم ایمیل اختصاصی ادمین‌ها (یکپارچه با cPanel)

یکی از بخش‌های خاص پروژه، ساخت خودکار صندوق ایمیل برای هر ادمین است:

- اتصال به **cPanel UAPI (Email::*)** با API Token (بدون نیاز به دسترسی WHM/ریسلر) برای ساخت/حذف خودکار mailbox هنگام افزودن/حذف ادمین.
- تعیین سقف حجم صندوق (Quota) و حداکثر حجم پیوست به‌ازای هر ادمین.
- **رمزنگاری AES-256-GCM** برای ذخیره‌ی امن پسورد mailbox در دیتابیس (قابل رمزگشایی، چون برای اتصال IMAP/SMTP لازم است).
- **ورود خودکار (SSO) به وبمیل Roundcube** از داخل پنل با توکن یک‌بارمصرف کوتاه‌عمر (بدون نیاز به تماس شبکه‌ای بین دو سرویس) — از طریق پل اختصاصی `webmail-integration/resa-mail-bridge.php`.
- کرون جاب پاک‌سازی خودکار پیوست‌های قدیمی ایمیل (`cron/mail-cleanup-cron.php`).

## ۴. زیرساخت، امنیت و اتوماسیون

- **نصب گام‌به‌گام از طریق مرورگر** (`install/install.php`) برای ساخت جداول و اولین حساب ادمین، با حذف پیشنهادی پوشه بعد از اتمام.
- ساخت خودکار جداول دیتابیس در صورت نبودن (`includes/db.php` با PDO).
- محافظت چندلایه با `.htaccess` (بلاک شدن دسترسی مستقیم به `config.php`، پوشه‌ی `includes`، آپلودها و پوشه‌ی پشتیبان‌ها).
- **قفل موقت حساب پس از تلاش‌های ناموفق ورود** (Rate limiting ساده).
- خاموش‌شدن خودکار نمایش خطاهای PHP در محیط تولید (تشخیص خودکار دامنه‌ی واقعی در برابر localhost).
- **کرون پاک‌سازی لاگ‌ها**: نگه‌داری جداگانه برای لاگ بازدید (۷ روز) و لاگ فعالیت/امنیتی (۳۰ روز، قابل تنظیم).
- تقویم/انتخاب‌گر تاریخ **جلالی (شمسی)** در پنل مدیریت.

## ۵. پشته‌ی فناوری (Tech Stack)

| بخش | فناوری |
|---|---|
| بک‌اند | PHP 8+ خالص (بدون فریم‌ورک)، PDO/MySQL |
| فرانت‌اند | HTML/CSS/JS خالص، فونت Vazirmatn |
| انیمیشن | GSAP، ScrollTrigger، Three.js |
| PWA | Service Worker، Web App Manifest |
| ایمیل | ادغام با cPanel UAPI + Roundcube (Webmail SSO) |
| امنیت | Session + CSRF، رمزنگاری AES-256-GCM، سطح دسترسی نقش‌محور |
| میزبانی هدف | هاست اشتراکی مبتنی بر cPanel |
